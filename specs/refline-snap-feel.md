# 参考线吸附手感（refline snap feel）技术方案

## 0. 结论摘要

用户主诉「拖拽时总对不上想要的线」。定位出五个手感缺陷（无真粘滞、方向过滤
无死区、贴合时反馈消失、边线不能对中心线、弱对齐截胡等距），按拍板落地五项
优化 + 独立复审全量收口。核心设计：**粘滞会话状态由 RefLineService 持有、作为
显式参数传入吸附纯函数**——纯函数保持幂等（docs/14 规则 3 的「显式会话状态」
口径）；吸附判定统一为「阈值内最近有效者胜」。零公开 API / Yjs 写入面变化；
E2E 用例经关粘滞验红（403）确认真门禁。

## 1. 问题与根因

| #   | 症状                                       | 根因（代码位置以实施时为准）                                     |
| --- | ------------------------------------------ | ---------------------------------------------------------------- |
| Q1  | 刚吸上、小幅过冲就脱钩，要明显回退才能再吸 | 吸附无状态：过线后 `dist<0` 被方向过滤丢弃、当帧不修正且红线消失 |
| Q2  | 手抖时参考线闪现/消失                      | 方向过滤按净位移符号、无死区——纯垂直拖的水平抖动使候选侧翻转     |
| Q3  | 完全对准时红线恰好消失                     | 距离 < 阈值/12 的线被「已贴合」跳过，matched 为空                |
| Q4  | 边对不到别人的中心线                       | kind 隔离：边线只与边线、中心线只与中心线配对                    |
| Q5  | 想要等距时被弱对齐抢线                     | 同轴对齐无条件优先于等间距                                       |

## 2. 拍板记录

- **粘滞方案：A3 + 粘滞增量**。保留方向过滤（不被未吸过的线回拽），上一帧
  命中线绕过方向过滤：拖过线 1~阈值 px 拉回、越阈即释放（跟手、无回弹）；
  更近的新线最近者胜、可正常切换。未采纳全双向磁井（误吸风险高、推翻 A3）。
- **边↔中心互吸放开**：拖拽与缩放同口径（拖拽三条线全参与配对；缩放被拖边
  可吸中心线）。kind 保留作粘滞身份。
- **对齐/等距同轴偏差最小者胜**：偏差 = |修正后位移 − 期望位移|，平局对齐胜。
- **视口裁剪不改**（用户拍板）：完全出视窗的图形不作参照。
- **释放措辞**：实现是阈值处硬切换（主流交互惯例），不称「平滑释放」、不加
  释放斜坡——统一「越阈即释放（跟手、无回弹）」。
- **已贴合跳过移除**：阈值内（含亚像素缝隙）一律修正并命中画线。

## 3. 设计要点

- 纯函数（`adsorber.ts`）：`snapRect(rect, dx, dy, refs, threshold, sticky?)`
  与 `snapResize(rect, dir, refs, threshold, minSize = 8)` 幂等；`IStickyRefLines`
  为显式入参，非函数自读取。
- Service（`refLineService.ts`）：`sticky` 字段记录上一帧命中线
  （`matchedVDefs/matchedHDefs`，kind+pos），`hideMatches()`（四个 up/cancel 调用
  点收口）与深缩放早退清空；合并策略按偏差最小者胜，败者轴的 matched/gaps/
  sticky 一并清空（红线只画胜者）。
- 粘滞匹配 key：`${kind}:${pos.toFixed(3)}`，与 `buildRefLines` 线集去重同源。
- 方向死区：`DIRECTION_DEAD_ZONE_RATIO = 1/3`（6 屏幕 px 阈值 → ≈2 屏幕 px）；
  边界取 `>=`（净位移恰等于死区时仍定向，保 A3 既有用例语义）。
- 缩放取**阈值内最近有效线**：吸附后尺寸 < minSize 的候选（典型：过近的中心
  线）跳过、回退次近有效边线，不整轴放弃。

## 4. 测试方案

- 纯函数单测（`adsorber.test.ts`）：粘滞六例（拉回/保持/越阈/无入参 A3 保持/
  更近切换/中心线）+ 幂等（含 sticky）+ 死区两例 + 亚像素贴合 + 互吸两方向 +
  缩放互吸/贴合/minSize 回退 + 热路径护栏（`toFixed` spy：空粘滞零格式化、
  单粘滞 ≤ 集合 1 次）。
- 服务层（`refLineService.test.ts`）：粘滞生命周期（两帧拉回、hideMatches 后
  不拉回、深缩放清粘滞）；同轴竞争（等距偏差小胜/对齐偏差小胜）。等距命中会
  画徽标（PIXI Text 测量），node 环境需 `stubPixiCanvasDocument`。
- E2E（`refline.spec.ts` C 用例）：吸上后过冲 3px 松手，断言落库 x 精确等于
  参照左缘。**验红法**：临时把 `snapRect(..., this.sticky)` 换成 `undefined`
  → 用例红在 403（脱钩停在线外），恢复后绿。
- 手工验证见 §7。

## 7. 手工验证（不写入 docs）

1. 拖元素接近参照边缘：红线出现、吸上；继续小幅过冲 1~5px——被拉回、红线
   不灭；推过 ≈6 屏幕 px——释放跟手。
2. 纯垂直拖动时水平抖动：接近线侧不闪线。
3. 完全对准：红线保持显示（不再消失）。
4. 把元素边拖到参照中心线附近：可吸（红线落在中心线上）。
5. 三件同排、拖中间件：等距解比对齐线更近时橙色徽标胜出；反之红线胜。
6. 缩放小件贴到参照中心线过近（会压过最小尺寸）时：回退吸到参照边线。

## 8. 边界与已知取舍

- 参照物仍限可视区内（完全出视窗不参与，用户拍板）；旋转件/连线/画笔/脑图
  不参与（docs/05 §8 降级口径）。
- 深缩放（zoom > 6x）跳过吸附；粘滞随之清空。
- 粘滞不跨拖拽会话（up/cancel 即清），缩放路径不引入粘滞（无方向过滤）。
- 同轴对齐与等距互斥（偏差小者胜）；异轴并存。
