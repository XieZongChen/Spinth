# 等间距端部链式（spacing end-chain）

## 0. 结论摘要

用户发现：三个同排图形拖中间件有橙色等距徽标，拖两端件没有。根因是 `axisSpacing`
要求**两侧同时有邻居**（`lefts/rights` 任一为空即返回）——docs/06 §7 的既定规格
（原单测「只有一侧邻居不触发」锁定）。本批扩展为**端部链式**：被拖件单侧有邻居
（≥2）时，与最近邻的间隙吸附到「最近邻与其外侧连续次邻的间隙」，显示两段等值
徽标。中置语义不变。

## 1. 拍板记录

- 端部链式（用户选定）：拖 A（左端）→ `gap(A,P) = g(P,Q)`；右端镜像。
- **只取最近邻 + 其外侧连续次邻一对**：跳过最近邻与远邻配对会破坏「A 与最近邻
  间隙」的语义（且解可能压到位于中间的其他邻居）。
- `g ≤ 0` 不触发：邻居对贴合时链式解等价于边对齐吸附（A 贴 P），留给对齐语义，
  避免双重吸附。
- 端部无中心等距类比（无「两邻正中」语义）——非目标。
- 合并策略不变：链式走 refLineService 既有「对齐/等距偏差最小者胜（平局对齐胜）」。

## 2. 算法（解析解，轴通用）

- 右端链（A 最左，rights ≥ 2）：按 main 升序 P=最近邻、Q=次邻；
  `g = Q.main − P.right`；解 `A.right = P.main − g`；`|Δ − d| < threshold` 吸附。
- 左端链镜像：P=main 最大的左邻、Q=其外侧；`g = P.main − Q.right`；
  解 `A.left = P.right + g`。
- 徽标两段（axis 顺序）：`[A↔P, P↔Q]` / `[Q↔P, P↔A]`，值均 g，cross 取被拖件
  cross 中点（与中置口径一致）。解构造上不与任何邻居重叠。

## 4. 手工验证（不写入 docs）

1. 摆三个同排等距图形，分别拖两端调间距：接近等距时出两段橙色徽标并吸附；
   拖中间行为不变。
2. 两端外侧再无第三件（被拖件只有一个邻居）→ 不出链式徽标（无参考间隙）。
