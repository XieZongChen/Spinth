# 网络拓扑 / 架构图（Network Topology / Architecture）功能规格

> 状态：**设计定稿，待实施**。本文件是 docs/13 阶段 4「常见图能力」第 3 项的功能锚点；
> 前置底座为 `specs/symbol-widget.md`（SYMBOL 控件），4.7 BPMN 复用同一底座。
>
> 已拍板（用户决策，不再重开）：
>
> 1. 设备图元用**新增的 SYMBOL 控件**承载，不扩 `ShapeType`。
> 2. 标签在图形外、计入 bbox。
> 3. 图标为内置 SVG 资产。
> 4. `eng-database / eng-queue / eng-file / eng-folder` 在符号控件中各有一份。
>
> 审计口径：避障与沿边锚点已随 4.1 落地（docs/13 §4.3 已对齐），本文不重复设计。

## 0. 摘要

### 0.1 一句话

用 SYMBOL 控件（图标 + 外置标签）做设备图元，配 **矩形 + 标题 + 编组** 近似区域，复用
4.1 的锚点 / 端口 / 全局避障，交付「10+ 设备 + 区域 + 正交避障线路」的拓扑样本。

### 0.2 关键决策

| 编号 | 决策     | 结论                                                        | 主要理由                                            |
| ---- | -------- | ----------------------------------------------------------- | --------------------------------------------------- |
| D1   | 图元承载 | `SYMBOL` 控件，首批 13 个图标                               | 标签外置 + 矢量 + 零资产；详见 symbol-widget        |
| D2   | 区域近似 | `SHAPE`（无填充 + 虚线框）+ `TEXT` 标题 + 编组              | 4.4 容器落地前的近似；编组已提供整体移动            |
| D3   | 避障口径 | 无填充 SHAPE 不入障碍集合（前置小改）                       | 区域框体积大，若当障碍会把所有内部连线逼到框外      |
| D4   | 锚点     | 符号图形区四边 + 显式 `startPort/endPort`；同边多线默认 0.5 | 复用 4.1，不新增锚点算法                            |
| D5   | 路由     | `ELBOWED` + 全局避障 + 拐点手柄；不新增路由算法             | 4.1 已交付；本项只做规模校验                        |
| D6   | 布局     | 纯手工 + 网格 / 参考线 / 对齐；不做自动布局                 | 拓扑图语义布局成本高、收益低；4.3 完成标志不要求    |
| D7   | 输出     | PNG（选区 / 全画布）；SVG 不做                              | 阶段 4 全部只做 PNG（docs/13 §4.0）                 |
| D8   | 语义     | 不做设备连接规则 / 拓扑校验 / 导入导出                      | 校验属于 4.7 可选项；本期只保证「画得出来、读得懂」 |

### 0.3 不做什么

- 容器语义（裁剪、带子移动、子元素归属）——4.4 的 FRAME；
- 自动布局 / 自动连线 / 设备图标状态（端口号、告警、在线离线）；
- 网络协议语义、配置导入导出（设备清单 JSON / 拓扑校验）；
- line jump、线束（bundle）、SVG 导出。

## 1. 完成定义

1. 一张拓扑图能放下 **10+ 设备**（服务器 / 路由器 / 交换机 / 防火墙 / 云 / 负载均衡 /
   互联网 / 用户 / 数据库 / 存储），每个设备有名字；
2. 至少一个**区域 / 集群**（矩形 + 标题），区域内的设备随区域整体移动；
3. 设备之间的正交连线**避让第三方设备**，不出现穿模；同侧多线可读（默认共享中点，
   需要分开时手动拖端点）；
4. 撤销 / 重做、刷新恢复、项目文件往返、PNG 导出、只读打开全部成立；
5. E2E 与双平台视觉基线入库，`pnpm verify` 与全量 E2E 绿。

### 2.3 符号承载的审计结论

20 型形状按「图形是否靠内部细节识别 / 文字是否有干净主体」分为三类：

- **文字容器（16 型）**：rect、round-rect、ellipse、diamond、triangle-up/down、
  parallelogram-left/right、stadium、document、hexagon、predefined-process、
  trapezoid-up/down、delay、off-page——流程图语义，文字居中在框内是正确画法；
- **混合态（2 型）**：`eng-database`、`eng-queue`——端头已让开、文字在「身」里，
  架构图里更常见「图标 + 下方名字」；
- **偏符号（2 型）**：`eng-file`、`eng-folder`——折角 / 标签页占据顶部，文字被挤到剩余区。

代码取证：`insetRectOf` 为 11 型单独写了内接箱（菱形半箱、三角下半箱、页连接让出下尖、
圆柱让出端头），全部是「文字放进轮廓」的设计；全库只有 3 型有内部细节线，而网络符号靠
细节线识别。结论：**形状模型没有「图形区 / 标签区」两段几何，符号必须新增控件**，
细节设计见 `specs/symbol-widget.md`。

存量 `eng-*` 形状保持不动（老文档零迁移），符号侧另做一份同语义图标。

## 5. 区域 / 集群（4.4 前的近似）

### 5.1 组成

一个区域 = 三个对象 + 一次编组：

1. 矩形：`SHAPE`，`fill: 'none'`（无填充）、`borderStyle: 'dashed'`、宽度 1~2；
2. 标题：`TEXT`，放在矩形左上角内侧（8px 内边距），内容如「生产 VPC」；
3. 设备与连线：放在矩形范围内；
4. 编组：矩形 + 标题 + 设备一起编组（`cmd/ctrl+g`），拖动即整体移动。

线**不纳入编组**：锚定线按不变式不得持有 `groupId`（docs/18 §2），且线随锚定节点移动
自动跟随；强行进组会让端点重映射语义变复杂。

### 5.2 避障豁免（前置小改）

**问题**：`collectRouteObstacles` 会把两端点外扩 120px 内的所有非 LINE/PEN 控件都当障碍。
区域矩形体积大，会把区域内所有连线的路径逼到框外，拓扑图直接不可用。

**决策**：障碍收集跳过 `fill === 'none'` 的 SHAPE。

**理由**：无填充 = 只描边、没有遮挡实体；线从标注框 / 区域框上穿过比绕一大圈更符合直觉。
副作用是「无填充标注框不再挡线」，属于同一条语义的修正。

**影响面**：

- `collectRouteObstacles` 一处谓词 + 单测（无填充框不入障碍、实填充框仍入障碍）；
- 现有 E2E F-4（避障）用的是实填充形状，不受影响；
- 文档：docs/08 §4 补一句口径。

### 5.3 层级

区域矩形必须在设备与连线**之下**：创建顺序「先框后设备」，或在层级菜单里对矩形「置底」。
视觉上虚线框不与设备描边争抢。E2E 用创建顺序保证，不依赖手工操作。

### 5.4 选择语义

- 单击区域 / 任一设备 → 选中整个组（编组语义，docs/18）；
- `Alt` + 单击 → 直选组内单个设备（进组，docs/18 §4.2），随后可双击改名；
- 框选半个组 → 该组不入选（docs/18 §4.3 口径）；
- 删除组 = 删除成员（含设备与标题），连线随之解绑并保留为悬空线（可用「清理悬空连线」）。

### 5.5 明确不做

- 裁剪（设备超出区域不裁）；
- 移动区域自动收编 / 释放内部设备（归属由编组显式表达）；
- resize 区域不缩放内部设备；
- 区域标题的自动布局 / 折叠 / 嵌套。

### 5.6 4.4 落地后的升级路径

FRAME 控件到位后，区域 = FRAME（标题 / 背景 / 子元素归属 / 裁剪可选），本节的
「矩形 + TEXT + 编组」写法保留为兼容路径；拓扑样本届时可平移升级，不强制迁移旧文档。

## 6. 连线与路由

### 6.1 锚点与端口

- 设备连线落在**符号图形区**四边（symbol-widget §3.4），不落在标签带；
- 同边多线默认 0.5 单点引出（2026-11-15 B），需要分开时把端点拖到目标位置写显式 port；
- 悬停连接点 / quick-add ghost 与真实锚点同源（4.1 已有）。

### 6.2 线型与箭头

- 默认 `ELBOWED`（新线一律折线，4.1 口径）；直线 / 曲线可用；
- 箭头默认终点实心箭头；双向链路两端都设箭头；
- 线宽 2 为默认，跨区域主干可用 2~4 区分层级；
- 线上标签用于链路说明（如「HTTPS 443」），单标签 ratio 定位。

### 6.3 避障规模校验

- 现有预算：`OBSTACLE_PAD = 120`、`MAX_OBSTACLES = 32`（按中心距取近者）；
- 校验方法：样本图 10+ 设备 + 区域，逐条线读 `__spinthDebug.__debug` 的
  `lastRouteObstacles` 计数，确认没有「关键障碍被截断导致穿模」；
- 若发现截断：优先提高预算或按「与线段相交优先」排序（改 `collectRouteObstacles` 一处），
  不做视口过滤（先正确后性能，docs/13 §4.0）；
- 性能护栏：单线重路由仍在既有 bench 口径内（16 候选 × 8 段 × 32 障碍 ≤ 1ms）。

### 6.4 已知取舍

- 从设备下方进入的连线会横穿标签带（symbol-widget §3.4）：样本布局尽量从侧上方进入；
- 线穿过无填充区域框是预期行为（§5.2）；
- 自环 / 同边多自环 / 拐点手柄：4.1 已有，拓扑样本不强制覆盖。

## 7. 文本与标签

| 对象     | 载体            | 样式                       | 编辑              |
| -------- | --------------- | -------------------------- | ----------------- |
| 设备名   | SYMBOL `label`  | 单行 16 / 24，居中，主题色 | 双击 / 单击已选中 |
| 区域标题 | TEXT            | 默认正文样式，可加粗       | 双击              |
| 链路说明 | LINE `text`     | 线上单标签                 | 双击线            |
| 图例     | TEXT + 符号组合 | 手工摆放                   | 同左              |

不做专门的图例 / 标题控件；图例就是「符号 + 文字」的手工组合。

## 8. 吸附与对齐

- 网格吸附：视图偏好（`localStorage`，不入文档），拖拽 / 缩放 / 创建 / 自由线端点四处量化；
- 参考线：符号与区域都参与（referenceable 能力位），含粘滞与等间距链；
- 对齐 / 分布：按 bbox（含标签带）走通用实现；同尺寸符号天然同基线。

## 9. 交互与编辑

### 9.1 创建

- 工具坞选「符号」→ 二级菜单选设备 → 单击 / 拖拽放置（连击可连续放）；
- 默认尺寸 96×128；放置后单击选中、再单击或双击进编辑；
- 区域：先画矩形（形状工具，无填充 + 虚线），再放 TEXT 标题，最后放设备。

### 9.2 连线

- 连线工具从设备拖出，端点吸附到图形区四边；同边多线默认重叠，需要时拖端点分开；
- 智能 quick-add 在符号上同样可用（落定形状默认矩形——本期不做「快速加同类符号」，
  挂账）。

### 9.3 移动 / 编组

- 单个设备拖动走通用矩形拖拽（吸附 / 参考线 / 边缘滚屏）；
- 整组拖动走编组拖拽（组 bbox + 成员一起），线自动跟随；
- Alt 进组直选单体。

### 9.4 删除 / 撤销 / 只读

- 删除设备：关联线解绑为悬空线（4.1 语义），可一键清理；
- 撤销：创建 / 命名 / 连线 / 移动 / 删除各为独立撤销步（500ms 捕获窗内合并）；
- 只读：符号工具禁用、双击不进编辑、ActionBar 隐藏；图仍可平移缩放与导出。

## 10. 数据与兼容

- 无新增 schema（本项只消费 `SYMBOL`）；区域是既有 SHAPE + TEXT + groupId；
- 项目文件：符号零资产条目；导入时未知 symbol id 走占位图（symbol-widget D7）；
- 多标签：只读跟随与单写者语义不变；
- 旧文档：没有符号 → 渲染逐字节不变；反向（旧客户端开新文件）跳过未知类型 + warning。

## 11. 性能

- 规模：10–30 个符号 + 5–10 条线，渲染与空间索引压力可忽略；
- 路由：重锚定 / 拖拽 / 重路由时重算避障（既有语义），障碍上限 32；区域不入障碍后
  候选数量下降；
- 无需新开性能优化；若样本实测掉帧，先查 culling 与 obstacles 预算，不改架构。

## 12. 验收

### 12.1 E2E（`network.spec.ts`）

- N-1 工具坞建 10 个设备：模型计数、类型、默认种类正确；连击不退出工具。
- N-2 命名：双击输入 → 回车落库；标签在图标下方、宽度内裁剪；Esc 不落库。
- N-3 锚点：从设备底边拉线，端点 y = 图形区底边（≠ bbox 底），线随设备移动。
- N-4 区域：矩形 + 标题 + 设备编组后整体拖动，标题与设备位移一致；Alt 单击直选设备。
- N-5 避障：三设备一条直线，首尾连线绕开中间设备（探针读取障碍集合、路径不穿 AABB）。
- N-6 无填充区域不挡线：线从区域框上穿过（前置小改的回归）。
- N-7 同边多线：两条线从同一设备右边出发默认重叠；拖端点分开后各自落库。
- N-8 撤销 / 重做：建组、移动、删除各一步；撤销后层级与位移恢复。
- N-9 持久化：刷新后符号 / 标签 / 组 / 线全部保真。
- N-10 项目文件往返 + PNG 导出：设备与文字存在（像素采样 / 文件条目断言）。
- N-11 只读：工具禁用、双击不进编辑、ActionBar 不出现。

### 12.2 视觉基线

- 场景 `network-sample`：云区域（矩形 + 标题）+ 10 个设备（服务器 / 路由器 / 交换机 /
  防火墙 / 负载均衡 / 云 / 用户 / 数据库 / 存储）+ 正交链路 + 线上标签；浅色主题，
  clip 到内容并清 UI（与 flowchart-sample 同款口径）；
- darwin / linux 双平台各一张，`--stability` 双跑全等后入库。

### 12.3 手工验收

1. 从空白画布按「区域 → 标题 → 设备 → 连线」顺序画一张 10 设备图，全程不用撤销。
2. 拖动区域：设备与标题一起动，线跟随，没有断线或错位。
3. Alt 单击区域内设备：只选中设备，改名后区域不变。
4. 拉一条穿过区域的线：线从区域框上穿过，不绕行；穿过设备时避让。
5. 缩放到 25% / 200%：图标与名字清晰（矢量），选择框与命中一致。
6. 深色主题：图标与名字对比度足够，区域虚线可见。
7. 导出 PNG：文字不糊、线不毛刺。
8. 只读标签页：图可读、不可改。

## 14. 风险与挂账

| 项                   | 现状 / 决策                           | 后续                                   |
| -------------------- | ------------------------------------- | -------------------------------------- |
| 区域不是真容器       | 矩形 + 标题 + 编组近似                | 4.4 FRAME 落地后升级                   |
| 编组内改名需要 Alt   | 编组选择语义                          | 双击直选（若真实反馈强烈）             |
| 线穿标签带           | 接受；样本从侧上方进入                | 标签避让（symbol-widget 挂账）         |
| 避障预算截断         | 10+ 设备实测；必要时改排序 / 提高预算 | 视口过滤（先正确后性能）               |
| 快速加「同类符号」   | quick-add 落定仍是矩形                | 按设备类型快速加节点（4.6 前后评估）   |
| 无填充框不挡线       | 全局口径变更，随前置小改落地          | 若用户要求「标注框挡线」，再加显式开关 |
| 设备图标语义（状态） | 不做                                  | 与 BPMN / 监控语义一并评估             |
