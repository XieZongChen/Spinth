# 00 — 总览

## 1. 产品定位

spinth 是本地优先的白板与思维导图编辑器。首版只做单机：

- 打开即用，无需登录、服务端或网络；
- 文档、撤销历史和图片资产保存在浏览器；
- 交互体验对标专业白板工具，但范围聚焦在画布编辑本身。

## 2. 架构

```
app  ── 只消费 ──▶  react  ── 只消费 ──▶  core
```

- `@spinth/core`：Yjs 文档、DataProcessor、PIXI 渲染、控件 Model/Vm/Service、
  选择/拖拽/编辑/吸附/剪贴板。
- `@spinth/react`：zustand 只读镜像、命令转发、DOM UI（工具栏、操作栏、菜单、
  空态、错误态、移动端布局）。
- `@spinth/app`：Vite + React 应用壳、主题、文档路由、顶栏。

## 3. 不变量

1. 所有写操作只写 Yjs；渲染只订阅 Yjs。
2. 拖拽/缩放期间只允许视觉预览，松手必须经 Model 写回。
3. 依赖显式注入，禁止全局单例。
4. 单文件单职责，目标 < 400 行。
5. 本地优先：没有网络时编辑、撤销、刷新恢复仍然可用。

## 4. 当前范围

已包含：画布、形状、文本、便签、连线、画笔、图片、脑图、编组、对齐/分布、
旋转、参考线、富文本、橡皮、撤销/重做、本地持久化、本地资产库。

暂不包含：账号、云端同步、多人协作、服务端资产端点。协同只保留未来扩展位，
当前版本不启动任何网络连接。
