# 10 — 未来协同边界

> 本文只定义扩展边界；当前版本是单机版，不启动任何网络连接。

## 1. 数据层

- 继续使用 Yjs 文档和既有 origin 纪律。
- 远端 update 的 origin 必须是 provider 实例，不能进入本地 undo 栈。
- provider 只能作为可选服务注入，不能成为 DataEngine 的硬依赖。

## 2. 文档

- 协同不改变控件 schema；未知字段在旧客户端保留。
- 远端数据仍走 schema 校验、clamp 和长度上限。

## 3. 资产

单机资产是 `spinth-asset:<sha256>` 本地引用。跨设备协同需要额外的资产传输层
（例如服务端 blob 端点）；在该层落地前，不应把本地资产引用当作跨设备可读 URL。

## 4. UI

协同时才增加连接状态、成员光标、离线提示；单机版顶栏只显示本地保存状态。

## 5. 服务端

当前仓库不包含 server 包。未来若增加，必须独立成包，并通过明确协议与客户端
解耦；服务端不得依赖 core/react 的控件与 UI 语义。
