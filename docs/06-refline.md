# 06 — 参考线吸附（对齐辅助线）

## 1. 设计目标

拖动/缩放元素时，与可视区内其他元素自动对齐并显示贯穿参考线；吸附手感
「磁吸 + 粘滞」，不抖动。深缩放不产生幻影吸附。

## 2. 参照线模型

- 参照物：可视区内的 SHAPE / STICKY / TEXT / IMAGE（连线/画笔/脑图不参与），
  剔除当前选中集。
- 每个参照矩形生成 6 条线：
  - 垂直：`vl`（左）、`vc`（中）、`vr`（右）；
  - 水平：`ht`（上）、`hc`（中）、`hb`（下）。
- 线的存储 key：坐标 3 位小数精度的字符串（`v:123.456`），规避浮点误差。
- 数据结构：`vLineMap / hLineMap: Map<key, IRefLineMeta[]>`，懒计算 + 脏标记。
- 重算时机：选中集变化、视口变化、模型创建/删除、文档级 update 旁路
  （拖拽/缩放进行中的其他元素几何变化）。

## 3. 吸附算法

```ts
interface AdsorbContext {
  distance?: number; // 吸附阈值，默认 6 屏幕像素
  scale: number;
  direction: 'left' | 'right' | 'top' | 'bottom' | 'center-x' | 'center-y' | corner;
}
```

流程：

1. 阈值 = `distance / scale`（屏幕像素 → 世界坐标）。
2. 只有被拖动方向的边参与吸附；缩放时只吸附被拖的边。
3. 按移动方向找最近参考线（距离 ≥ 0.5），磁吸修正 delta。
4. 粘滞：已吸附时反向轻移在阈值内不脱离；越过阈值平滑释放。
5. 中心线只与中心线对齐，边线只与边线对齐。
6. 深缩放保护：`threshold < 1` 世界单位（zoom > 6x）跳过吸附。

常量：`ADSORB_DISTANCE = 6`；反抖动 epsilon 随 threshold 屏幕化
（约 0.5 屏幕 px）。方向感知候选：移动轴 delta > 0 只取前方线，< 0 只取后方线；
纯垂直拖动的水平轴不过滤。

## 4. 参考线绘制

- 命中的参考线与目标矩形投影合并为贯穿两者的长线段。
- 屏幕恒定粗细：`lineWidth = 2 / scale`；主题色为红色系。
- 绘制时机：RectEditor/拖拽每次 bounds 更新实时刷新；pointerup 清除。
- 绘制层：`optionLayer`。

## 5. 交互细节

- 吸附修正作用于选区 bounds；落库时同样应用修正（视觉 = 数据）。
- 多选时以选区外接矩形整体参与吸附。
- 拖拽中参考线显示；松手清除。

## 6. 验收

- [x] 拖动矩形接近另一矩形边缘 6px 内自动贴合 + 显示红色贯穿线。
- [x] 已吸附时反向轻移不脱离，超过阈值正常脱离。
- [x] 中心对中心、边对边不串扰。
- [x] 缩放到 0.1x 时吸附阈值与 1x 手感一致。
- [x] undo/微移/对齐/远端移动后重拖，吸附与红线在**当前**几何上。
- [x] zoom 4x 下 1 屏幕 px 级缝隙仍会被贴合修正。
- [x] 向右拖动越过参照线后不被身后的线回拽。
- [x] 等间距：三元素拖中间者，两侧间隙相等时显示橙色距离徽标并吸附。

## 7. 等间距参考线

- 触发：拖动中与两侧邻居的间隙接近相等 → 吸附到精确等距位置并显示距离徽标。
- 邻居条件：同轴投影重叠、矩形语义控件、剔除选中集。
- 两种等距：
  1. 边间隙等距：`gapL = A.x − L.r`、`gapR = R.l − (A.x + A.w)`；
     `|gapL − gapR| < threshold` 时解 `gapL = gapR` 的解析解。
  2. 中心等距：被拖中心在两邻中心正中。
- 优先级：同轴对齐吸附优先；异轴可并存。
- 视觉：橙色系；每个间隙一枚距离徽标（胶囊底 + 整数 px），间隙桥线；
  绘制层 optionLayer，pointerup 清除。
- 数学约束：解析解，非迭代逼近；多选作用于选区外接矩形。
