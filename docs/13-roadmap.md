# 13 — 路线图与决策台账

## 1. 当前基线

- 画布与渲染：PIXI 无限画布、视口、按需渲染、空间索引与 culling。
- 控件与编辑：SHAPE / TEXT / STICKY / LINE / PEN / IMAGE / MIND_MAP；多选 / 编组 /
  对齐 / 分布 / 参考线；富文本 / 排版 / 橡皮分段擦除；旋转手柄入口暂隐藏
  （rotation 数据能力保留，specs/rotate-hide）。
- 数据与平台：Yjs + IndexedDB 持久化 / undo / compaction；本地资产与图片生命周期；
  多标签单写者 + 只读跟随；项目文件导出 / 导入（`.spinth.zip`）；PWA / Service Worker。
- 移动与可访问性：390px 移动端工具菜单；只读态收口（右键不建选区、呈现门禁、
  运行时降级序列，docs/21 §4）；语义色 / 对比度 / 键盘协议（specs/a11y-closeout）、
  字号单位（specs/rem-typography）。
- 版本与门禁：`1.0.1`（tag `v1.0.1`），仓库开源；1.0 是首个公开 API 基线；
  1155 单测（core 1039 + react 78 + app 38）、E2E 49 spec / 253 例（251 通过 +
  2 跳过）、视觉 4/4、`pnpm verify` 通过；明细见 docs/15。

#### 4.1 标准流程图

**状态**：已完成（specs/flowchart-closeout）。

**能力**：

  「白底黑框」可达（docs/04 §8.3）。
- 锚点沿边参数化：`startPort/endPort` + 同边多线错开（纯派生、加删线后仍均分）；

- ELBOWED 全局避障（`collectRouteObstacles` 单源、无解 fallback）、紧凑自环

  单事务一步撤销；500ms 捕获窗与前一删除命令隔离（前置 stopCapturing）。

**验收**：`flowchart.spec.ts` 15 例（F-1…F-8 + F-3b/c 轮廓锚点、F-5b/c 同边自环/

#### 4.2 组织架构 / 树

**现状（审计起点）**：MIND_MAP 是单 widget + 递归节点树；左右布局、文本节点、
拖拽重排 / 跨图、Tab/Enter、方向键、删除、整图移动；无折叠、无上→下布局、
无组织卡字段（姓名 / 职务 / 部门）；模板系统已移除（docs/11 §0）。

**检查范围（审计）**

- MIND_MAP 的布局 / 节点样式 / 折叠 / 排序 / 增删 / 撤销 / 导出；组织架构真实
  样本（CEO → 部门 → 组）。
- 方案：MIND_MAP 布局 profile（`layout: 'mind' | 'org'`）vs 新 ORG_CHART 控件
  vs 形状 + 正交线模板；节点字段是否必须结构化。
- 上→下 tidy tree、同级间距、节点尺寸随文本、折叠 / 展开、跨部门排序。

**补足 / 开发（审计后拍板；MVP 优先 A）**

- A：MIND_MAP 增组织架构布局 profile——上→下、层 / 同级间距、正交连接线、
  节点卡样式、折叠 / 展开；复用增量树 / 拖拽 / 快捷键 / 整图移动。
- B：新 ORG_CHART 控件（结构化字段 / 部门列）；成本高，作为 A 不满足时的后置。
- 无自动布局的兜底：形状 + 正交线模板文档 / 示例，不作主路径。

**完成标志**：3 层组织架构、折叠、重排、导出；E2E / 视觉；docs/11 同步（若改
MIND_MAP 语义）。
**规格**：specs/org-chart.md（实施时建）。

**规格**：specs/bpmn.md（实施时建）。

#### 4.8 执行纪律

- 每项顺序：审计（代码 / docs / E2E / 真实样本）→ 范围拍板 → `specs/<feature>.md`
  （检查结论、验收清单、手工步骤）→ types → 纯逻辑 + 单测 → VM / Service →
  E2E / 视觉基线 → docs 同步。
- 每项独立提交、可回退；不跳序。底座在首次被需要时落地；若某底座阻塞当前项，
  把它提前到当前项内实现，并保持后续复用接口稳定。
- 新控件走三件套 + 注册表；不改 dataEngine / vmEngine；公共 API 增量走
  allowlist / 类型锁；新控件必须同时接入只读、持久化、导出、剪贴板、撤销。
- 完成前 `pnpm verify` + 相关 E2E；关键图种补视觉基线；样本图进入 E2E 夹具。
- 本阶段不做：服务端 / 协同、SVG 导出（backlog）、BPMN 执行语义 / XML、UML
  模型校验（MVP 不做）。

### 阶段 5 — 协同（最后）

- 前置评估按 docs/10；只有 1.0 稳定且有真实多设备需求才启动。
- 不建 `packages/server`，不把 `y-websocket` 放进默认启动路径，不改单机离线语义。
- 启动时先补 editBlocked 交互面矩阵（docs/21 §4）与 Awareness/wsProvider 边界。

## 3. 决策与挂账

- 阶段 1–2（发布前工程债、开源发布 v1.0）已完成；当前主计划为阶段 4（常见图
  能力），阶段 3 平台收口并行，阶段 5 协同最后且不进入默认启动路径。
- 常见图能力七项顺序固定：标准流程图 → 组织架构 / 树 → 网络拓扑 / 架构 →
  跨职能 / 泳道 → UML 时序 → UML 类图 / ER → BPMN；每项先审计再拍板范围，
  不跳序（阶段 4）。
- 容器 / Frame 在 4.4 首发；4.3 集群先用矩形 + 标题近似，4.5 框架 / 4.7 池泳道
  复用容器；不提前造完整容器。
- 全局避障在 4.3 首发：`routeElbow` 扩第三方 obstacles，调用方收集可视 / 邻近
  bounds；4.4–4.7 复用。
- 箭头族（空心 / 鸦爪 / 虚线）与两端标签在 4.6 首发；4.5 用现有 open / solid /
  dashed 起步，4.7 复用 4.6；旧文档零迁移。
- BPMN 只做核心子集，不做执行语义 / XML 导入导出；矢量导出（SVG）列 backlog，
  本阶段只做 PNG。
- 常见图能力的验收清单与手工步骤写 `specs/<feature>.md`，不写入 docs。
- 1.0 是首个公开 API 基线：运行时公共面 = `createBoard()` 冻结投影 + DEV 调试入口
  （specs/runtime-narrowing）；1.0 后破坏性变更走主版本。
- 多标签：单写者 + 只读跟随，接管 = 整页刷新，不做实时同步（docs/21）。
- 只读态分层：core 修语义（右键不建选区、降级序列、工具钳制），react 修呈现
  （持久铬件禁用、浮动件随附着对象隐藏）；命令层守卫是安全网不是呈现面
  （docs/21 §4）。
- 项目文件：`fflate` + `.spinth.zip`、导入新建画布、外链保留 + warning、未知条目
  忽略 + warning（docs/20）。
- 单机断网：无 `wsUrl` 即无阻断路径；用「OfflineBar 不出现 + 断网仍可编辑 / 撤销 /
  落盘」固化不变量（docs/10 §4）。
- 视觉基线必须入库并由 `check-visual-baselines` 守护；不保留未跟踪 actuals 假绿。
- 协同挂账：editBlocked 交互面矩阵（等 `wsUrl` 进入启动路径，与只读独立，
  docs/21 §4）。
- 可访问性遗留：画布内容元素级朗读（独立内容层）、ToolGhost / 画布图形对比度
  （需产品判断）、ToolFlyout Tab 顺序（portal 与 390px 裁剪冲突）——specs/
  a11y-closeout §13.5；图标随字号缩放与字号刻度归一另案（specs/rem-typography
  §13.4）。
- 版本策略：1.0.x 只修 bug，破坏性变更走主版本。
